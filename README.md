# מה סיכמנו?

**POC של מערכת AI לבעלי מקצוע שמגיעים לבית הלקוח** – בגרסה זו: אינסטלטור בלבד.

המערכת שומרת רצף ברור של כל העבודה – מהשיחה הראשונה עם הלקוח ועד סיום העבודה – כך שבכל רגע אפשר לענות על השאלה "מה סיכמנו?": מה הוערך, מה נמצא בשטח, מה הוצע, מה אושר ומה בוצע בפועל.

## הרעיון המרכזי

```
שפה טבעית  ←  מידע מובנה  ←  פעולה במערכת
```

- **ה-AI הוא שכבת הבנה בלבד** – הופך תיאור חופשי ("הסיפון סדוק וצריך להחליף אותו") למידע מובנה: בעיה, עבודה, חלקים, פעולות ופריטי מחירון.
- **ה-AI לא קובע מחירים** – המחיר מחושב בלוגיקה דטרמיניסטית ממחירון קבוע. פריט שאינו במחירון נזרק.
- **Human in the Loop** – בעל המקצוע רואה ומתקן כל תוצאה של ה-AI לפני שהיא ממשיכה הלאה.

## תהליך העבודה

| # | שלב | מי | מה קורה |
|---|---|---|---|
| 1 | פתיחת עבודה | בעל מקצוע | תיאור הבעיה מהשיחה → הערכה ראשונית מהמחירון |
| 2 | אבחון בשטח | בעל מקצוע | תיאור מה שנמצא → מידע מובנה שניתן לתקן |
| 3 | הצעת מחיר | מערכת | חישוב מהמחירון בלבד |
| 4 | אישור | מזמין העבודה | אישור או דחייה – האישור נשמר כ-Baseline |
| 5 | תוספת | שניהם | תוספת בשפה טבעית → תמחור → בקשת אישור נפרדת למזמין |
| 6 | סיום | בעל מקצוע | מה בוצע בפועל |
| 7 | **מה סיכמנו?** | שניהם | הערכה, הצעה, אישורים, תוספות, סכום מאושר מול ביצוע בפועל וההפרש, השוואה פר-פריט ויומן אירועים |

## הפעלה

אין התקנה, אין build ואין תלויות – זה קובץ HTML אחד.

- **הכי פשוט:** לפתוח את `index.html` בדפדפן.
- **דרך שרת מקומי** (מומלץ לבדיקות אוטומטיות בדפדפן):

  ```bash
  python -m http.server 8765
  ```

  ואז לגלוש ל-<http://localhost:8765>.

### מצבי AI

- **ללא מפתח (ברירת מחדל):** ניתוח מקומי מבוסס מילות מפתח – מספיק להדגמה ("נזילה", "סיפון", "ברז ניל", "סתימה" ועוד).
- **עם Claude:** במסך ⚙ הגדרות מזינים מפתח Anthropic API, והניתוח עובר ל-Claude. אם הקריאה נכשלת – המערכת חוזרת אוטומטית לניתוח המקומי.

> ⚠️ במצב Claude המפתח נשלח ישירות מהדפדפן. זה מתאים להדגמה מקומית בלבד – לא לאתר ציבורי. לשימוש אמיתי יש להעביר את הקריאה לשרת.

הנתונים נשמרים ב-`localStorage` של הדפדפן, כך שרענון הדף לא מוחק את העבודה.

## מה בכוונה לא נכלל ב-POC

מקצוע אחד בלבד, מחירון קטן, טקסט בלבד, Web פשוט. אין WhatsApp, תשלומים, CRM, אפליקציה, תמונות, קול או מערכת משתמשים. המטרה היא POC עובד מקצה לקצה שמדגים שימוש אמיתי ב-AI בתוך תהליך עסקי – לא מוצר מסחרי.
